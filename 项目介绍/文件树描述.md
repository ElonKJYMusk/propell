## 关键文件详解

### ⭐⭐⭐ core/main.py
- `app = FastAPI(title="propell2image API")` — FastAPI 应用实例
- `app.add_middleware(CORSMiddleware)` — 全局 CORS 开放
- `app.mount("/storage", StaticFiles)` — 静态文件挂载
- `app.include_router(chat.router)` — 聊天路由注册
- `app.include_router(settings.router)` — 设置路由注册
- `@app.websocket("/ws/{canvas_id}")` — WebSocket 端点

### ⭐⭐⭐ services/agent_service.py
- `create_agent()` — 创建 LangGraph ReAct Agent（20 工具+动态 Prompt）
- `process_chat_stream(messages, session_id)` — 异步生成器，yield SSE 事件
- `Recursion_limit = 200` — 从环境变量读取

### ⭐⭐⭐ services/stream_processor.py
- `StreamProcessor` — SSE 流式引擎类
- `process_stream(agent, messages)` — 执行 agent.astream() 并 yield SSE 事件
- `_handle_message_chunk(message_chunk)` — 处理三种 chunk 格式
- JSON 增量解析 — `tool_call_args_buffer` + json.loads() try/except

### ⭐⭐⭐ services/prompt.py
- `SYSTEM_PROMPT` — ~2500 tokens 角色定义
- `get_full_prompt(tools, skills, workspace)` — 模块化装配
- 包含提示词优化建议（自动追加"高清""4K"等 magic words）

### ⭐⭐⭐ tools/volcano_image_generation.py
- `generate_volcano_image_tool(prompt, size)` — 文生图
- `edit_volcano_image_tool(prompt, image_url, size)` — 图生图编辑
- `download_and_save_image(url, prompt)` — sRGB 归一化 + JPEG/PNG 决策
- `parse_size(size)` — 8 种宽高比 + 自定义 WxH + API 格式

### ⭐⭐⭐ frontend ChatInterface.tsx
- `Message` / `ToolCall` TypeScript 类型定义
- SSE 消费循环 (`fetchEventSource` 或 `fetch` + ReadableStream)
- `pendingMediaRef` — 画布挂载前的媒体队列
- Base64 清理 (`sanitizeArguments()`)
- 工具调用卡片渲染 (图片/音频/视频/3D)

### ⭐⭐ frontend ExcalidrawCanvas.tsx
- `ExcalidrawCanvasHandle` — 命令式 API (`useImperativeHandle`)
- `computeNextPosition()` — 智能排布算法（Y 重叠分组 → 行内 X 排序）
- `drainPendingMedia()` — 清空待插入媒体队列

### ⭐⭐ services/skill_service.py
- `scan_available_skills()` — 扫描 public/ + custom/ 目录
- `get_skills_context()` — 构建 Progressive Loading XML 块
- `_parse_skill_md(md_path)` — YAML frontmatter 解析
- `set_skill_enabled(skill_id, enabled)` — 原子写入 settings.json

### ⭐⭐ services/workspace_service.py
- `get_workspace_context()` — 构建 <workspace> XML 块
- `_is_empty_or_template()` — 空/默认模板跳过
- `_truncate()` — 5000 字符截断（前 70% + 后 20%）

## 代码调用链追踪

```
用户输入 "生成一张赛博朋克城市图"
  │
  ├─ 1. ChatInterface.tsx: handleSend()
  │     POST /api/chat {message, canvas_id}
  │
  ├─ 2. chat.py: chat_endpoint()
  │     stream_and_save() → process_chat_stream()
  │
  ├─ 3. agent_service.py: process_chat_stream()
  │     create_agent() → factory.create_llm() → ChatOpenAI
  │                    → tools list (20 @tool)
  │                    → get_full_prompt(tools, skills, workspace)
  │                    → create_react_agent(model, tools, prompt)
  │     StreamProcessor(agent).process_stream(messages)
  │
  ├─ 4. stream_processor.py: process_stream()
  │     agent.astream({"messages": [...]}, config={"recursion_limit": 200})
  │     → yields chunks
  │
  ├─ 5. stream_processor.py: _handle_chunk()
  │     chunk → AIMessageChunk → delta 事件 (streaming text)
  │     chunk → tool_call_chunks → JSON 增量解析 → tool_call 事件
  │
  ├─ 6. volcano_image_generation.py: generate_volcano_image_tool()
  │     parse_size("16:9") → "2560x1440"
  │     POST /images/generations {model, prompt, size, n=1}
  │     → image_url → download → ICC sRGB → save JPEG (quality=95)
  │     → return json.dumps({image_url: "/storage/images/xxx.jpg"})
  │
  ├─ 7. stream_processor.py: _handle_message_chunk()
  │     ToolMessage → tool_result 事件
  │
  ├─ 8. chat.py: stream_and_save()
  │     manager.broadcast(canvas_id, event) — WebSocket 广播
  │     [DONE] → HistoryService.save_canvas()
  │
  └─ 9. ChatInterface.tsx: SSE consumer
        tool_result.content → image_url → pendingMediaRef.enqueue()
        → ExcalidrawCanvasHandle.addImage() → computeNextPosition()
        → 画布渲染
```

## 扩展指南

- **如何添加新的 LLM 提供商**：在 `app/llm/` 下创建新文件，继承 `base.BaseLLMProvider`，在 `factory.py` 添加分支
- **如何添加新的生成工具**：在 `app/tools/` 下定义 Pydantic args_schema + @tool 函数，在 `agent_service.py` 的 tools 列表注册
- **如何添加新的 Skill**：在 `skills/custom/<id>/` 下创建 SKILL.md（含 YAML frontmatter），在设置页启用
- **如何添加新的前端页面**：在 `components/` 下创建组件，在 `App.tsx` 添加 page 查询参数判断
- **如何添加新的工作区文件**：在 `workspace_service.py` 的 WORKSPACE_FILES 字典中添加条目
