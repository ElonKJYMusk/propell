# propell2image 运行指南

## 环境配置

### 基础要求

| 项目 | 最低版本 | 推荐版本 | 说明 |
|------|---------|---------|------|
| Python | 3.9 | 3.11 | 3.9 需要额外添加 `from __future__ import annotations` |
| Node.js | 18 | 20+ | 前端构建 |
| 操作系统 | Windows / macOS / Linux | — | 无特殊要求 |
| 磁盘 | 1GB+ | 5GB+ | 存放生成的媒体文件 |
| 内存 | 4GB+ | 8GB+ | 视频处理 (MoviePy) 需要内存 |

### 依赖安装

```bash
# 后端
cd propell2image/backend
pip install -r requirements.txt

# 前端
cd propell2image/frontend
npm install
```

| 包 | 用途 |
|------|------|
| fastapi + uvicorn | Web 框架 + ASGI 服务器 |
| langgraph + langchain | Agent 编排引擎 |
| langchain-openai | LLM 接入（OpenAI 兼容接口） |
| Pillow | 图片 sRGB 归一化 |
| moviepy | 视频拼接 |
| pydub | 音频混音 |
| opencv-python | 人脸检测 |
| httpx + requests | HTTP 客户端 |

### 环境变量

```bash
cd propell2image/backend
cp env.example .env
# 编辑 .env，填入 API Key
```

**必需的环境变量：**

| 变量 | 说明 | 示例 |
|------|------|------|
| LLM_PROVIDER | LLM 提供商 | volcano 或 siliconflow |
| VOLCANO_API_KEY | 火山引擎 API Key | ark-xxxxxx |
| VOLCANO_IMAGE_MODEL | 图片生成模型 | doubao-seedream-5-0-260128 |
| VOLCANO_VIDEO_MODEL | 视频生成模型 | doubao-seedance-1-5-pro |
| VOLCANO_MODEL_NAME | LLM 模型 | doubao-seed-2-0-pro-260215 |

**可选环境变量：**

| 变量 | 默认值 | 说明 |
|------|--------|------|
| RECURSION_LIMIT | 200 | Agent 最大推理步数 |
| MOCK_MODE | false | Mock 模式（调试用，不调 API） |
| DASHSCOPE_API_KEY | — | 阿里云百炼（TTS + 多模态理解） |
| COMFYUI_SERVER_ADDRESS | — | ComfyUI（虚拟人生成） |
| LOG_LEVEL | INFO | 日志级别 |

## 服务启动

### 后端启动

```bash
cd propell2image/backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

启动成功后：
```
INFO: Uvicorn running on http://0.0.0.0:8000
```

**验证**：
```bash
curl http://localhost:8000/health
# → {"status":"ok"}
curl http://localhost:8000/
# → {"message":"propell2image API","status":"running"}
```

### 前端启动

```bash
cd propell2image/frontend
npm run dev
```

启动成功后：
```
VITE v5.x  ready in xxx ms
➜ Local: http://localhost:3000/
```

## 首次使用

1. 浏览器打开 `http://localhost:3000`
2. 点击「新建项目」或直接输入对话
3. 在聊天框输入创作需求，如"生成一张赛博朋克风格的都市夜景"
4. Agent 自动调用工具生成图片并插入画布
5. 点击右上角齿轮进入设置页——配置工具、Skill、环境变量

## 常见问题

### 启动报错 `ModuleNotFoundError: No module named 'app'`
**原因**：不在 backend 目录下执行 uvicorn
**解决**：先 `cd backend` 再启动

### 启动报错 `TypeError: unsupported operand type(s) for |`
**原因**：Python 3.9 不兼容 `Type | None` 语法
**解决**：确认 skill_tools.py 中 `Path | None` 已改为 `Optional[Path]`，相关文件已添加 `from __future__ import annotations`

### 对话发送后无响应
**原因**：LLM API Key 未配置或无效
**解决**：检查 `backend/.env` 中的 `VOLCANO_API_KEY` 是否正确

### 图片生成后聊天框和画布颜色不一致
**原因**：ICC Profile 导致的跨渲染路径色差
**解决**：确保 Pillow 已安装（`pip install Pillow==10.4.0`），工具会自动进行 sRGB 归一化

### 视频生成超时
**原因**：火山引擎视频 API 排队时间长或视频复杂
**解决**：视频默认 600 秒（10 分钟）超时，如需调整修改 `volcano_video_generation.py` 中的 `max_wait_time`

### 画布上 3D 模型预览无法加载
**原因**：OBJ 文件内部的路径引用未修复
**解决**：model_3d_generation.py 的 `extract_obj_zip()` 已自动修复路径引用。如果仍有问题，检查 ZIP 包中是否包含标准 OBJ 结构

### npm install 失败
**原因**：Node 版本过低或网络问题
**解决**：确保 Node >= 18，可以尝试 `npm install --registry=https://registry.npmmirror.com` 使用国内镜像

### 设置页修改不生效
**原因**：某些配置需要重启后端（如 LLM_PROVIDER）
**解决**：Skill 启用/禁用无需重启；工具开关无需重启；.env 修改需要重启 uvicorn
