## 子流程 1: 前端发送消息

### 1.1 入口: ChatInterface.tsx handleSend()

**文件**: `frontend/src/components/ChatInterface.tsx`

用户输入文本并点击发送 → `handleSend()`:
1. 构造 Message 对象 `{role: "user", content: inputText}`
2. 追加到 messages 数组（UI 立即渲染）
3. 构建请求体 `{message: inputText, messages: history, canvas_id: currentCanvasId}`
4. 调用 fetch POST `/api/chat`

```typescript
const response = await fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message: inputText, messages: history, canvas_id: canvasId })
})
```

**关键决策**: `canvas_id` 从 URL 查询参数获取——如果用户从首页创建了新项目，`canvas_id` 在 URL 中；如果首次对话没传，后端会自动创建新 canvas。

### 1.2 SSE 流消费

```typescript
const reader = response.body!.getReader()
const decoder = new TextDecoder()
let buffer = ''

while (true) {
  const { done, value } = await reader.read()
  if (done) break
  buffer += decoder.decode(value, { stream: true })
  const lines = buffer.split('\n')
  buffer = lines.pop() || ''  // 保留最后一行（可能不完整）
  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const payload = line.slice(6)
      if (payload === '[DONE]') return  // 流结束
      const event = JSON.parse(payload)
      dispatchEvent(event)  // delta → 文本追加, tool_call → 工具卡片, tool_result → 更新状态
    }
  }
}
```

**设计要点**: `buffer` 机制——UTF-8 多字节字符可能被 chunk 边界切断，保留最后不完整行到下一次循环，避免 JSON 解析失败。

## 子流程 2: 后端接收请求

### 2.1 入口: chat.py chat_endpoint()

**文件**: `backend/app/routers/chat.py`

路由 `POST /api/chat` → `chat_endpoint(request: ChatRequest)`:
1. 从请求体提取 `message`, `messages`, `canvas_id`
2. 如果有 `canvas_id` 且是新项目 → 调用 HistoryService 创建
3. 返回 `StreamingResponse(stream_and_save(), media_type="text/event-stream")`

```python
@router.post("/chat")
async def chat_endpoint(request: ChatRequest):
    messages = request.messages or [
        {"role": "user", "content": request.message}
    ]
    canvas_id = request.canvas_id or f"canvas-{int(datetime.now().timestamp())}000"
    return StreamingResponse(stream_and_save(messages, canvas_id),
                             media_type="text/event-stream",
                             headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"})
```

### 2.2 异步生成器: stream_and_save()

```python
async def stream_and_save(messages, canvas_id):
    assistant_content = ""
    tool_results = []
    try:
        async for event in process_chat_stream(messages):
            # 累积助手回复内容
            if '"type":"delta"' in event:
                data = json.loads(event[6:])  # 去掉 "data: " 前缀
                assistant_content += data.get("content", "")
            # 累积工具结果
            elif '"type":"tool_result"' in event:
                tool_results.append(json.loads(event[6:]))
            yield event
            await manager.broadcast(canvas_id, event)  # WebSocket 广播
    finally:
        # 无论正常结束还是异常中断，都持久化
        yield "data: [DONE]\n\n"
        HistoryService().save_canvas(canvas_id, messages, assistant_content, tool_results)
```

**设计要点**: `finally` 块确保即使中间抛异常，对话历史也会被保存——用户的输入和已生成的内容不会完全丢失。

### 3.2 process_chat_stream()

**文件**: `backend/app/services/agent_service.py:93-148`

```python
async def process_chat_stream(messages, session_id=None):
    langchain_messages = []
    for msg in messages:
        if msg.get("role") == "user":
            langchain_messages.append(HumanMessage(content=msg.get("content", "")))
        elif msg.get("role") == "assistant":
            langchain_messages.append(AIMessage(content=msg.get("content", "")))

    agent = create_agent()
    processor = StreamProcessor(session_id)

    async for event in processor.process_stream(agent, langchain_messages):
        yield event
```

**关键决策**: 消息历史中只转换 user 和 assistant 角色——system 角色消息由 LangGraph 内部通过 `create_react_agent` 的 `prompt` 参数注入，不在消息历史中手动添加。

## 子流程 4: 流式引擎核心

### 4.1 StreamProcessor.process_stream()

**文件**: `backend/app/services/stream_processor.py:78-154`

```python
async def process_stream(self, agent, messages):
    langchain_messages = []  # 已在上层转换
    chunk_count = 0

    async for chunk in agent.astream(
        {"messages": langchain_messages},
        {"recursion_limit": self.recursion_limit},  # 默认 200
        stream_mode=["messages"]
    ):
        chunk_count += 1
        async for event in self._handle_chunk(chunk):
            yield event  # 每个 SSE 事件立即 yield

    yield "data: [DONE]\n\n"
```

**`astream()` 的参数**:
- `{"messages": langchain_messages}` — 输入状态，包含消息列表
- `{"recursion_limit": self.recursion_limit}` — 运行时配置，限制最大步数
- `stream_mode=["messages"]` — 只流式输出消息类型的更新

### 4.2 _handle_chunk() 三路分发

**文件**: `backend/app/services/stream_processor.py:156-209`

```python
async def _handle_chunk(self, chunk):
    # 格式 1: tuple (chunk_type, chunk_data)
    if isinstance(chunk, tuple) and len(chunk) == 2:
        chunk_type, chunk_data = chunk
        if chunk_type == "values":
            async for event in self._handle_values_chunk(chunk_data):
                yield event
        else:
            # 处理消息流
            for message in (chunk_data if isinstance(chunk_data, list) else [chunk_data]):
                async for event in self._handle_message_chunk(message):
                    yield event

    # 格式 2: list [message1, message2, ...]
    elif isinstance(chunk, list):
        for message in chunk:
            async for event in self._handle_message_chunk(message):
                yield event

    # 格式 3: 直接消息对象
    else:
        async for event in self._handle_message_chunk(chunk):
            yield event
```

**为什么有三种格式**: LangGraph 的 `astream()` 输出格式取决于图的结构和当前步骤。简单的单步推理返回直接 message 对象，多步推理（有工具调用/返回）返回 tuple `("messages", [AIMessage, ToolMessage])`，状态更新返回 tuple `("values", {"messages": [...]})`。

```python
def download_and_save_image(image_url: str, prompt: str = "") -> str:
    # 1. HTTP 下载
    response = requests.get(image_url, timeout=60)
    response.raise_for_status()

    # 2. sRGB 归一化（如果 Pillow 可用）
    if Image is not None:
        im = Image.open(BytesIO(response.content))
        # ICC Profile → sRGB
        icc = im.info.get("icc_profile")
        if icc:
            src = ImageCms.ImageCmsProfile(BytesIO(icc))
            dst = ImageCms.createProfile("sRGB")
            im = ImageCms.profileToProfile(im, src, dst)
        im.info.pop("icc_profile", None)

        # 3. 透明/不透明格式决策
        has_alpha = im.mode in ("RGBA", "LA")
        is_transparent = has_alpha and im.getchannel("A").getextrema()[0] < 255
        if not is_transparent:
            filename = os.path.splitext(filename)[0] + ".jpg"
            im.convert("RGB").save(file_path, format="JPEG", quality=95, optimize=True, progressive=True)
        else:
            filename = os.path.splitext(filename)[0] + ".png"
            im.save(file_path, format="PNG", optimize=True)
    else:
        # Fallback: 直接写字节
        with open(file_path, "wb") as f:
            f.write(response.content)

    return f"/storage/images/{filename}"
```

## 子流程 6: WebSocket 广播与持久化

### 6.1 广播

**文件**: `backend/app/services/connection_manager.py:18-30`

```python
async def broadcast(self, canvas_id: str, message: str):
    if canvas_id not in self.active_connections:  return
    dead = []
    for ws in self.active_connections[canvas_id]:
        try:  await ws.send_text(message)
        except Exception:  dead.append(ws)
    for ws in dead:
        self.disconnect(canvas_id, ws)  # 清理断开连接
```

```python
def save_canvas(self, canvas_id, messages, assistant_content, tool_results):
    data = self._load_data()  # JSON 数组
    canvas = next((c for c in data if c["id"] == canvas_id), None)
    if canvas:
        canvas["messages"] = messages + [{"role": "assistant", "content": assistant_content}]
        canvas["updatedAt"] = datetime.now().isoformat()
    else:
        data.insert(0, {  # 新画布插入最前面
            "id": canvas_id,
            "name": extract_title(messages),
            "messages": messages + [{"role": "assistant", "content": assistant_content}],
            "createdAt": datetime.now().isoformat(),
```
